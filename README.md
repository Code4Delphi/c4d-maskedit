## ⚙️ Installation
1 - Abrir projeto C4DMaskEdit.dpk 

2 - Dar o Build e o Install

3 - No Delphi, acessar o menu Tools > Options > Language > Delphi > Library > Library path > Clicar no botão "..." > Selecionar a pasta "C4D-MaskEdit\Src" > Clicar no botão Add

4 - O componente com nome TC4DMaskEdit sera adicionado a paleta C4D
